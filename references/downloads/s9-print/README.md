# §9 — Physical / Print Books

These cannot be automatically downloaded. Acquire via bookstores, libraries, or ILL.

## Checklist

- [ ] **I Ketut Bangbang Gde Rawi — *Wariga Dewasa* / *Kalender Bali*** (standard almanac; Balinese bookstores)
- [ ] **Arya Suryawan — *Ala-Ayu Padewasan Wariga Dewasa*** (Tokopedia: https://www.tokopedia.com/mbukubali/ala-ayu-padewasan-wariga-dewasa)
- [ ] **Ida Pedanda Gede Buruan — *Padewasan Kapelek*** (primary source for folio 11a Alahing Sasih citation)
- [ ] **Fred B. Eiseman — *Bali: Sekala and Niskala Vol. I*** (ethnographic; library or second-hand)
- [ ] **Ian Proudfoot — *Old Muslim Calendars of Southeast Asia* (Brill, 2006)** (ILL via university library)
